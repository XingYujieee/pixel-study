# 像素书房

第一人称像素风格的个人笔记软件。在一间方块书房里走动，从书架上拿书、坐到书桌前写 Markdown / Word / TXT。笔记就是库文件夹里的普通文件，可以与 Obsidian 共用同一个库。

## 设计原则

1. **文件第一**：笔记、灵感、模板都是库里的普通文件，Obsidian 能直接打开；书房布局、打开记录等附加数据放在应用数据目录，不写进库。
2. **好玩的只改画面，动文件的必须由你明确触发，而且能撤销**：书脊蒙灰、天气变化、鱼塘冒泡、放书弹跳都只是外观；移动、放生（移到 `.trash/`）、覆盖等操作只在你点了按钮之后发生，并且都有退路（撤销、备份、冲突比较、草稿恢复）。
3. **不打扰**：没有通知、打卡、分数和排名。旧灵感只会让鱼塘冒泡，走过去才看得到。

## 书房里有什么

| 东西 | 用法 |
| --- | --- |
| 书架 | 收藏书架放任意文件的引用；文件夹书架显示库里某个文件夹。久没碰的书蒙灰，被 3 篇以上笔记引用的书发亮（暂停菜单可关闭） |
| 书桌 | 坐下写作。Markdown / TXT 用 CodeMirror，Word 用页面式编辑器（有丢失风险的格式会先提示，首次保存前自动备份） |
| 工作台 | 做新书：选类型（Markdown / Word / TXT）和**鱼饵（模板）**。内置文献卡片、读书笔记、会议记录、日记；库里 `Templates/`（或 Obsidian 模板插件设置的文件夹）中的文件也会列出，变量写法与 Obsidian 相同 |
| 鱼塘 | **灵感池**。书房里按 C、任何地方按 ⌘⇧I 随手记一句，存成 `Inbox/` 下的 Markdown。在鱼塘里写成笔记、放上书架（移到书架对应的文件夹）或放生（移到 `.trash/`，可撤销）。偶尔冒泡：浮上来一条放了几天的灵感或一本很久没翻的书 |
| AI 工作台 | 接 Claude / OpenAI / 兼容接口问答，可附上当前笔记，回答可插入笔记或存成新笔记。密钥存在系统钥匙串 |
| 资料箱 | 分拣台：列出还没上架的导入文件，多选后一次放上书架（文件夹书架移到对应文件夹，收藏书架只加引用）；也能浏览全部资料 |
| 窗台 | **窗景**：六种内置像素风景（树林、海边、雪山、竹林、田野、城市，天空透明、夜里亮灯）；窗外是立体的方块地形（按风景换成树林、田野、雪山、海岛、竹林、城市），更远处一圈远景画，雾把两者接起来；自己的照片像素化（默认 256 像素宽、32 色）后抠掉天空、挂成远景，露出真实的日出日落和星星；宽图可以绕屋子一圈做全景；每扇窗可以单独换；**把图片从访达直接拖到窗户上**也行。时间（跟随现实 / 加速循环 / 固定）；天气（自动 / 固定 / 跟随鱼塘 / **跟随现实**：选一个城市，用 Open-Meteo 查实时天气） |
| 地毯 | 空手点一下设置氛围：雨声、炉火、夜读（深夜光线）。站上去生效，走开恢复 |
| **拖放导入** | 从 Finder 把文件或文件夹拖进窗口，指着的家具会发光、顶部提示去处。丢在文件夹书架 → 复制到那个文件夹；收藏书架 → 复制到 `Imports/` 并上架；书桌 → 导入后直接打开；鱼塘 → `Inbox/`；AI 工作台 → 附进对话；资料箱或地上 → `Imports/` 待分拣。文件变成旋转的小书弹出、再飞进家具。原文件只复制，同名自动保留两份，文件夹保留子目录，库里已有的文件不重复复制；回执里可以撤销（副本移到 `.trash/`）。专注模式下拖进来导入到 `Imports/` |
| 换屋子（T） | 七种主题：书房、极简白屋、林间木屋（壁炉和烟囱）、塔楼图书馆（拱窗）、海边灯塔（圆窗）、地下书库（没有窗，屋顶长草）、和室（纸拉窗）。墙、地板、窗户、屋顶、灯光和默认窗景一起换，家具和文件不动 |
| 像 Notion 一样写 | Markdown 默认「所见即所得」：光标不在的行直接显示效果（标题、粗体、高亮、下划线、颜色、能点的待办方块、圆点列表、引用、分割线、表格），光标所在行显示原文，文件内容不变。行首或中文后输入 /（中文输入法下是「、」）弹出命令菜单，可以打字或拼音首字母筛选：标题、待办、列表、引用、表格（划过选几行几列）、提示框、代码块、分割线、双链、图片、公式、日期。选中文字出现工具条：字号（标题级别 / 小字）、粗体、斜体、下划线、删除线、高亮、行内代码、双链、八种文字颜色。光标在表格里出现表格工具条：加行加列、删行删列、对齐；Tab 跳格并自动对齐。写出来的都是 Obsidian 认得的写法（<u>、==、<small>、<span style="color">、> [!note]） |
| 管家（G） | 一只跟着你的方块小鸟（猫头鹰 / 鹦鹉 / 麻雀，可以改名）。平时停在书架顶上，按 G 叫出来，飞到你肩膀旁边。问它「三体在哪」会告诉你在几楼哪个书架，并飞过去带路（自动上下楼、进门）；让它「整理书架」会按文件夹重新排书架，书多了自动加楼层；「种三棵树」「砍掉这棵树」「除草」打理花园；「记一下……」进鱼塘；还能新建、移动笔记（一定先问你，能撤销）。接上大模型（设置里填服务商、模型、API 密钥，和 AI 工作台共用）后能随便说，它用工具调用自己决定做什么；没接时也听得懂一组固定说法 |
| 楼层（=） | 书多了一层放不下就放楼梯、往上加一层（最多 9 层），每层有自己的书架、家具、挂件和屋子主题；一楼才有通往院子的门。书架面板里可以一层层点进子文件夹，「单独放一个书架」或「只放这一层」 |
| 两个时钟 | 顶栏左边：小钟是本机时间，天空盘是书房里的时间（可以加速、固定），还有当前楼层 |
| 院子与花园 | 左键南墙的门开门，出去是围栏围起来的院子：小路、花坛、菜地、草垛、野餐桌、长椅、井、路灯（天黑会亮）、柴堆。围栏以内都能走，不会无限扩张。空手点杂草就拔掉，杂草每天会长出几棵。走出门物品栏自动换成园艺工具（1 空手、2 树苗、3 花种、4 灌木、5 草垛、6 花坛、7 菜地、8 铲子）：准星对着地面出现绿 / 红格子，右键种下（种不了会说原因）；拿铲子对准东西按住左键，圆圈走满就挖掉（树要久一点，草垛一层层挖）。也可以交给管家 |
| 方块有体积 | 和方块游戏一样：一格高的书桌、工作台、箱子、草垛都能跳上去站着，半格高的花坛直接走上去；书架三格高跳不上去 |
| 书架名牌 | 每个书架顶上挂着名字；准星对准一本书时显示开头几行 |
| ⌘K 带路 | 搜索结果上按 ⌥Enter（或「带我去」）：走到那本书所在的书架前，书上方出现箭头并闪烁 |
| 黑板与画框 | 暂停菜单「挂到墙上」：黑板钉一篇笔记（待办、本周计划），笔记改了黑板跟着变；画框挂库里的图片（可像素化，三种尺寸） |
| 沙漏 | 书桌上的专注计时（15 / 25 / 45 / 60 分钟），沙子真的会漏，漏完轻轻一声铃 |
| 宠物（P） | 第一次打开就有一只橘猫「团子」。猫、狗、兔子、小鸡、狐狸（原创方块造型，最多三只）：溜达、跟着你、晚上趴在你最近看的书旁边睡觉，左键摸头冒爱心；你出门它会跟出来 |
| 唱片架 | 导入自己的音乐（mp3 / m4a / wav / aiff / flac，或整个专辑文件夹，复制到应用数据目录，不进笔记库）。读音乐文件里的专辑、歌手、曲序，同一专辑放进一张唱片；没有标签时用文件名（「歌手 - 歌名」「03 歌名」）。封面按唱片名画成 32×32 像素画：名字里有雨、夜、星、海、夏、山、林、雪、花、爱、城、火、猫、琴、咖啡等字会画对应的景，其他画抽象图案；可以「换封面」。一个唱片架放 10 张，放不下再放一个 |
| 留声机 | 交互参考《渔力全开》：对准唱片按 E 拿起来（拿在手上，F 拿到眼前看封面和歌单，Q 放回去）；对着留声机按 E 放上去，唱针落下开始放这张唱片，唱盘上印着封面；短按 E 打开播放面板（上一首 / 下一首、顺序 / 单曲 / 随机），按住 E 取下唱片。离得越远越小声。管家也会：「放张唱片」「放《叶惠美》」「有哪些唱片」 |
| 背景音乐（M） | 像 Minecraft 一样，隔一阵响起一首安静的小曲：每首现场作曲、不重复，有六种风格（钢琴、八音盒、氛围长音、圆舞曲（竖琴和长笛）、电钢琴（带贝斯）、田园（吉他和陶笛）），曲子有主题和再现；白天多大调，夜里和雨天多小调；风格可多选，频率可选关 / 偶尔 / 经常 / 一直，也可以立刻放一首；留声机放歌时自动让路 |
| 声音 | 全部现场合成：脚步（木地板、石地、软垫、草地不同）、开门关门、跳下来落地、翻书、放东西、抛竿、宠物叫声、雷声；环境声跟随屋子、天气和时间（雨、壁炉、海浪、虫鸣、鸟叫）；地毯可以设成雨声、炉火、海浪、风声、鸟鸣或你自己的音频；音效 / 环境 / 音乐分开调 |
| 与访达并排 | 一键把书房缩到左边、访达在右边打开库文件夹，方便直接拖文件进来 |
| 布局预设 | 暂停菜单里保存当前家具摆法、换成另一套。换之前自动保存当前摆法，可以换回来 |

## 运行

需要 macOS 11+、[Rust](https://rustup.rs)（stable）、Node.js 22、pnpm、Xcode Command Line Tools。

```bash
pnpm install
pnpm tauri dev          # 开发模式（热重载）
pnpm tauri build        # 打包 .app 和 .dmg（ad-hoc 签名，本机可运行）
```

也可以双击 `构建像素书房.command` 一键安装依赖并打包。打包结果在 `src-tauri/target/release/bundle/`。未经公证的应用首次打开时，在 Finder 中右键 → 打开。

> 第一次使用建议先备份笔记库，或用 Git 管理库目录。

## 测试

```bash
pnpm test                                                      # 前端单元测试（Vitest）
cargo test --manifest-path src-tauri/Cargo.toml --workspace    # Rust 文件层与 AI 接口测试
pnpm gen:vault test-vault 1000                                 # 生成 1,000 篇中文测试库
```

## 结构

```
src-tauri/crates/vault-core/   文件层（与 Tauri 无关，可单独测试）
  scope.rs    库边界与路径校验
  scan.rs / index.rs   扫描、索引与文件名映射
  io.rs       原子读写、写前校验、新建、不覆盖的移动
  links.rs    反向链接计数（[[维基链接]] 与相对路径链接）
  session.rs  运行时状态、监听对账、自写入过滤
  watch.rs    notify 监听 + 200ms 去抖
  search.rs   全文搜索
  appdata.rs  配置、最近打开、草稿、备份、按库保存的附加数据
src-tauri/crates/ai-core/      AI 接口（Anthropic / OpenAI 兼容，流式）
src-tauri/src/                 Tauri 命令（薄封装）
src/ipc/                       前端唯一调用 invoke 的地方
src/world/                     书房：布局规则、模型、纹理、引擎、天气、手持、主题、窗景、墙上挂件、宠物、声音合成
src/study/                     灵感池、模板、书脊状态、冒泡（纯函数，有单元测试）
src/app/                       状态与操作（study.ts 是鱼塘、模板、预设、地毯的入口）
src/notes/ src/word/           Markdown / TXT 与 Word 编辑会话
src/ui/                        界面组件
```

## 快捷键

| 键 | 作用 |
| --- | --- |
| W A S D / 空格 | 移动 / 跳 |
| 左键 / E | 与准星指着的家具或书交互 |
| 右键 / R | 放置手上的家具 / 旋转 |
| 1–9、0、-、= / 滚轮 | 选择物品栏（1 是空手，- 是留声机，= 是楼梯，最后一格唱片架用滚轮选）；院子里 1–8 是园艺工具 |
| E / F / Q | 拿起唱片 / 细看 / 放回；对着留声机按住 E 取下唱片 |
| X | 拆除家具（不删除文件） |
| C | 随手记一句，放进鱼塘 |
| ⌘⇧I | 任何地方随手记 |
| ⌘K / ⌘P | 搜索文件名和正文（⌥Enter 在书房里找到它） |
| ⌘O | 选择文件导入 |
| ⌘J | 书房 ↔ 全屏专注写作 |
| ⌘E | 切换预览 |
| ⌘S | 立即保存 |
| Esc | 菜单 / 关闭界面 / 从书桌起身 |
