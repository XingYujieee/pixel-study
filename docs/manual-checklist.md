# 手动验收清单（M1）

在 Mac 上用 `pnpm tauri dev` 或打包后的应用执行。先运行 `pnpm gen:vault test-vault 1000` 生成测试库，**不要直接用真实笔记库测试**。

## 输入法与编辑

- [ ] 系统拼音：连续输入“我想写一些笔记”，选字过程中候选窗紧贴光标
- [ ] 选字过程中按 Enter、Esc、方向键，只影响输入法，不触发保存 / 搜索 / 关闭弹窗
- [ ] 搜狗输入法重复上面两项
- [ ] 复制、粘贴、剪切、⌘Z / ⇧⌘Z 撤销重做正常（同时验证菜单栏“编辑 → 撤销”与编辑器撤销一致）
- [ ] ⌘K 搜索框、新建笔记对话框中用输入法输入中文，选字时按 Enter 不会提前提交

## 保存

- [ ] 输入停止约 1 秒后状态栏从“未保存”变为“已保存”
- [ ] ⌘S 立即保存
- [ ] 打开 CRLF 文件（测试库中 `读书笔记 0001.md`），编辑保存后用 `file` 或十六进制查看换行仍为 CRLF
- [ ] YAML 属性、中文路径、`[[链接|别名]]`、`^块引用` 保存后原样不变
- [ ] 保存期间立刻关闭窗口，重新打开后内容完整

## 与 Obsidian 交替修改

- [ ] 应用中打开某笔记（无未保存内容），在 Obsidian 中修改并保存：应用 3 秒内刷新，光标位置不跳
- [ ] 应用中输入但未保存时，在 Obsidian 中修改同一笔记：出现冲突界面，磁盘内容未被覆盖
- [ ] 冲突界面三个按钮分别验证一次
- [ ] 连续输入 2 分钟，不出现误报冲突
- [ ] 在 Finder 中删除正在编辑的笔记：出现“已被删除”横幅，不会自动重新创建
- [ ] 在 Finder 中重命名正在编辑的笔记：编辑器跟随新文件名（或按删除处理），内容不丢

## 异常退出

- [ ] 制造冲突后（未处理）在活动监视器中强制退出应用；重新打开后出现草稿恢复横幅，恢复后进入比较

## 文件

- [ ] 导入一个 PDF 和一个 Word 文件：出现在 `Imports/`，原文件修改时间不变
- [ ] 再次导入同名文件：询问保留两份或取消
- [ ] 点击 PDF / Word：显示文件卡片，“用系统应用打开”与“在 Finder 中显示”正常
- [ ] 预览中点击 Wikilink、相对链接跳转；外部网址在浏览器中打开；本地图片显示

## 性能（1,000 篇测试库）

- [ ] 冷启动扫描期间持续输入，没有明显卡顿
- [ ] ⌘K 搜索中文关键词，结果在 200ms 内出现
- [ ] 展开含 100+ 文件的目录，滚动流畅

## 鱼塘、模板、书脊、预设、地毯（在 Mac 上验证）

- [ ] 书房里按 C、专注写作时按 ⌘⇧I：弹出随手记；中文输入法选字时按回车不会提前保存
- [ ] 抛进去的灵感出现在库的 `Inbox/`，Obsidian 中能看到（带 created 与 tags 属性）
- [ ] 鱼塘里"放上书架"：文件移到书架对应的文件夹（收藏书架移到 `Notes/` 并出现在书架上）；Obsidian 中同步
- [ ] "放生"后文件在库的 `.trash/` 里；点"撤销"移回原处
- [ ] 天气选"跟随灵感池"，把下雨阈值调到 2：灵感 1 条晴、2–3 条雨、4 条以上雷雨（有闪电）；全部整理完放晴
- [ ] 工作台选"文献卡片"做一本 Markdown：属性与标题正确；在 Obsidian 中 `- [ ]` 显示为待办框
- [ ] 用模板做 Word：在 Word 中打开正常，标题下可以直接输入
- [ ] "把内置模板放进 Templates/"：文件出现；修改后工作台列出的是自己的版本
- [ ] 有 Obsidian 模板插件时（`.obsidian/templates.json` 设置了文件夹）：工作台读取那个文件夹
- [ ] 很久没改的书有灰；被多篇笔记 `[[链接]]` 的书发亮、有小光点；暂停菜单关闭后恢复原样
- [ ] 放一本书到收藏书架：书从上方落下、轻轻回弹
- [ ] 地毯设为"雨声""炉火"：站上去有声音，走开淡出；"夜读"：光线变成深夜；暂停菜单可关声音
- [ ] 布局预设：保存 → 拆几件家具 → 换回预设恢复；"载入前的摆法"可以换回来
- [ ] 书房里站几分钟：鱼塘偶尔冒泡（不弹窗）；点开鱼塘能看到浮上来的那条

## 拖放导入（在 Mac 上验证）

- [ ] 从 Finder 拖一个 PDF 到书房窗口：指着的家具发出黄色光框，顶部提示去处；移开到地上时提示"收进资料箱"
- [ ] 松手后：小书从落点弹出、再飞进家具；家具轻轻一弹；回执显示数量和去处
- [ ] 丢在文件夹书架：文件出现在那个文件夹，Finder 里原文件还在、修改时间没变
- [ ] 丢在收藏书架：文件进 `Imports/` 并出现在书架上；拖一个库里已有的笔记过去只加引用、不复制
- [ ] 丢在书桌：直接坐下打开；丢在 AI 工作台：对话框显示"附上拖进来的《…》"
- [ ] 拖一个带子文件夹的文件夹：结构保留；再拖一次：整个文件夹变成"名称 (1)"，不混进原来的
- [ ] 同名文件：保留两份，不弹窗
- [ ] 回执点"撤销"：副本在 `.trash/`，书架上的引用去掉
- [ ] 资料箱"待分拣"：多选后放上文件夹书架（移动）/ 收藏书架（只加引用）
- [ ] 专注写作模式下拖入：整屏提示，导入到 `Imports/`
- [ ] Retina 屏上落点准确（指着哪个家具就进哪个）

## 屋子、窗景、墙上、宠物、声音（在 Mac 上验证）

- [ ] 暂停菜单「换屋子」：七种主题都能切换，家具和书不动；木屋壁炉的火在跳；地下书库白天也是暗的
- [ ] 窗台「窗外风景」：内置风景切换；晚上城市和海边会亮灯
- [ ] 用自己的照片：「换成真实天空」后窗外能看到日落和星星；宽幅照片勾「全景」后三扇窗连起来
- [ ] 把一张照片从访达拖到某扇窗户上：那扇窗换成像素画；回执里能撤销
- [ ] 天气选「跟随现实」：搜城市（注意同名城市看国家），顶栏显示气温；断网时不报错，按自动天气
- [ ] 书架名牌字清楚；准星对准书显示开头几行
- [ ] ⌘K 搜一本书，按 ⌥Enter：走到书架前，书上方箭头、书在闪
- [ ] 挂黑板：钉一篇待办，在书桌上改这篇笔记后黑板跟着变；挂画框选一张图，切换像素风和尺寸；X 取下
- [ ] 书桌沙漏：选 1 分钟（可临时改代码）或 15 分钟，沙子往下漏，漏完响铃并提示
- [ ] 领养三只不同的宠物：会走动、跟着你、晚上去最近看的书旁边睡（Z 字）；左键摸头有爱心和叫声；改名、送回家
- [ ] 声音：第一次点进书房后能听到脚步声；下雨天有雨声、打雷；木屋靠近壁炉声音变大；地毯设成「海浪」站上去能听到
- [ ] 背景音乐：M → 「现在放一首」，多放几次能听到不同风格（钢琴、八音盒、氛围、圆舞曲、电钢琴、田园）；只勾一种风格时只放那种；设成「一直」后曲间约十几秒；留声机播放时背景音乐自动停
- [ ] 左上角只有时间和天气，没有库名；T 打开换屋子、P 打开宠物、M 打开声音
- [ ] 第一次打开新版本时屋里有一只橘猫「团子」（之前一只都没养的话）
- [ ] 跳上书桌、工作台、资料箱能站住；书架跳不上去；从桌上走下来会掉到地上并有落地声
- [ ] 左键门开门（吱呀声），走出去是院子；花坛直接走上去，草垛能一级级跳到两格高；围栏挡住出不去；站在门口时关不上门
- [ ] 出门后光线变成屋外的天光（地下书库也是）；脚步变成草地声，小路上是石头声；宠物跟着出门
- [ ] 窗外是立体方块地形，换窗景风景时地形跟着换；夜里路灯和城市窗户会亮
- [ ] 自己的图片：默认「中」像素和 32 色，远景清楚，不再糊成一片；之前装过的旧图要重新装一次才会变清楚
- [ ] 留声机：拖 mp3 到留声机上加歌，播放时唱片转、冒音符；走远变小声；顺序 / 单曲 / 随机；移出歌单
- [ ] 声音面板：各轨音量、全部静音、关掉「环境声跟随」
- [ ] 「与访达并排」：书房缩到左边，访达在右边打开库文件夹（第一次会询问是否允许控制访达）；从访达拖文件到书房家具上
- [ ] 第一人称手臂：从右下角伸出；左键挥一下有弧线；右键放东西往前推；走路时轻微晃动

## 管家、楼层、花园（在 Mac 上验证）

- [ ] 按 G：小鸟从书架顶上飞到肩膀旁边，右边出现聊天；Esc 收起后它还跟着；「回去吧」它飞回书架顶
- [ ] 没填 API：说「三体在哪」「整理书架」「除草」「种三棵树」「去二楼」能做；说别的会提示去设置
- [ ] 聊天里「设置」：填服务商、模型、密钥（钥匙串），状态从「离线」变成模型名；随便说话能调用工具
- [ ] 「整理书架」先弹确认；同意后按文件夹排好，多了会加楼层；「撤销」能恢复
- [ ] 问一本在二楼的书：它说在二楼哪个书架，点「带我去」会换到二楼、走到书架前，书在闪
- [ ] 新建 / 移动笔记一定弹确认；拒绝后文件不动；移动后「撤销」能移回去
- [ ] 物品栏 = 放楼梯；左键楼梯选楼层、加一层、改名、拆掉空楼层；上楼时黑一下；二楼没有门
- [ ] 院子里空手点杂草能拔掉；「砍掉这棵树」看着哪棵就砍哪棵；树种不到屋子旁边和小路上
- [ ] 顶栏左边：小钟（本机时间）和天空盘（书房时间），把书房时间调成加速后两者不一样
- [ ] 书架面板：子文件夹显示成文件夹格子，点进去看，上面有路径；「书架换到这里」「单独放一个书架」

## Notion 式编辑（在 Mac 上验证）

- [ ] 行首输入 /（拼音输入法下打「、」）弹出菜单；打「bg」筛到表格；↑↓ 选，回车插入；Esc 关掉菜单但不离开书桌
- [ ] 表格：划过格子选大小；Tab 跳到下一格（内容被选中，直接打字替换），最后一格 Tab 新起一行；表格工具条加行加列、删行删列、对齐
- [ ] 光标离开表格后显示成真正的表格；点某一格回到原文并落在那一格
- [ ] 选中文字出现工具条：字号、B I U S、高亮、代码、双链、颜色；⌘B / ⌘I / ⌘U 有效；再按一次取消
- [ ] 待办方块能点；勾上后整行变灰划线；⌘↩ 勾选
- [ ] 顶部「所见即所得 / 源码」切换；用 Obsidian 打开同一篇，下划线、高亮、颜色、提示框都显示正常
- [ ] 中文输入法选字过程中不弹菜单、不打断选字
